# Portes MineNorth Systeme

Les interfaces des portes utilisent désormais la même charte MineNorth que les interfaces de permis/boutiques de référence : panneau clair, bandeau bleu nuit, cartes, boutons avec survol et hiérarchie visuelle.

## Vente et location

Une porte personnelle peut être proposée :
- **Vente définitive** : prix en euros, paiement par carte via EuroBank, puis transfert de propriété au joueur acheteur.
- **Location temporaire** : prix + durée en jours, paiement par carte via EuroBank, puis accès temporaire au locataire jusqu'à l'expiration.

Les portes Police/Pompiers/Entreprise/Organisation ne peuvent pas être vendues ou louées.

La gestion se fait depuis le panneau de la porte en sneak + clic droit. Une porte annoncée affiche son offre au public et les actions Acheter/Louer.

Les données de vente/location sont persistées dans `config/Minenorth-systeme/porte.toml` et dans les SavedData du monde.
