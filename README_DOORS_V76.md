# MineNorth Systeme V76 — Maisons gérées par les OP

- Les maisons ne possèdent aucun propriétaire avant leur achat.
- Seuls les OP créent/configurent les portes personnelles des maisons et les mettent en vente ou en location.
- Un OP fait Shift + clic droit sur une porte non configurée, choisit Personnel, saisit le nom de la maison puis configure la maison.
- Toutes les portes d'une même maison utilisent exactement le même nom de maison.
- Une annonce peut être permanente (vente) ou temporaire (location + durée).
- Un joueur non propriétaire fait clic droit sur une porte annoncée pour acheter/louer.
- Achat : paiement via EuroBank, puis toutes les portes personnelles non attribuées du même groupe de maison sont transférées à l'acheteur.
- Location : paiement via EuroBank, puis le locataire obtient l'accès à toutes les portes du même groupe pendant la durée choisie. Aucun nom de propriétaire n'est affiché dans le menu public.
- Après expiration de la location, l'accès est automatiquement retiré.
- Après achat, le propriétaire peut gérer ses accès, mais la mise en vente/location reste une fonction réservée aux OP.
